# ⚡ Calculadora de Consumo Elétrico Inteligente

> Sistema simples e eficiente para estimar o consumo mensal de energia e o custo de aparelhos eletrodomésticos.

## 🎯 Objetivo do Projeto
Este projeto foi desenvolvido como parte de um desafio de introdução a sistemas. O objetivo principal é ajudar usuários a entenderem o impacto financeiro e energético de seus equipamentos no dia a dia, promovendo o consumo consciente de energia elétrica.

## 🧮 Fórmula para o Cálculo

O sistema realiza o cálculo com base na potência do aparelho e nas horas de uso diário estimadas para um período mensal padrão de 30 dias:

$$\text{Consumo Mensal (kWh)} = \frac{\text{Potência (W)} \times \text{Horas/Dia} \times 30}{1000}$$

> 💡 **Diferencial:** Além do consumo em kWh, o sistema multiplica o resultado por uma tarifa fixa estimada de **R$ 0,75 por kWh** para exibir o custo financeiro aproximado em Reais (R$).

## 🚀 Como Executar o Programa

### Pré-requisitos
Antes de começar, você precisa ter instalado em seu computador:
* O [Python 3.x](https://python.org) instalado.

### Passo a passo para rodar localmente:
1. Abra o terminal ou prompt de comando (CMD) do seu computador.
2. Navegue até a pasta onde está o arquivo `app.py`:
   ```bash
   caminhos para sua pasta/projetos/consumo-energia
   ```
3. Execute o programa digitando o comando abaixo:
   ```bash
   python app.py
   ```
4. Insira os dados solicitados pelo terminal (Nome, Potência e Horas de Uso) para ver o resultado na tela.
